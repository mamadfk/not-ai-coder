## 💡 چرا AI Code Diff Assistant؟

ابزارهای تجاری مثل Cursor یا افزونه‌های AI ماهانه **۲۰ دلار** یا هزینه‌های دلاری سنگین برای هر توکن API دریافت می‌کنند. اما آیا می‌دانستید سرویس‌هایی مانند:
- **Google AI Studio** (مدل‌های Gemini 1.5 Pro و 2.0 Flash با کانتکست عظیم ۱ تا ۲ میلیون توکن)
- **DeepSeek Playground**
- **OpenAI / Claude Playgrounds**
- **OpenRouter & HuggingFace**

همگی دسترسی‌های رایگان یا بسیار ارزان با کانتکست‌های غول‌پیکر در اختیار شما می‌گذارند؟ 

تنها چالش، **فرستادن کانتکست پروژه به این وب‌سایت‌ها** و **اعمال خودکار تغییرات AI روی فایل‌ها** بود. این افزونه این پل ارتباطی را به رایگان و بدون واسطه برای شما فراهم می‌کند!

## ✨ ویژگی‌های کلیدی

- 🌳 **خروجی ساختار درختی و سورس کامل**: تبدیل ساختار پروژه و محتوای فایل‌ها به یک پرامپت استاندارد، تمیز و شماره‌گذاری شده.
- 📁 **فیلتر هوشمند پوشه‌ها**: امکان انتخاب دستی پوشه‌های مورد نظر (از سایدبار یا QuickPick) جهت کاهش حجم پرامپت.
- 🧩 **پشتیبانی از فرمت‌های مدرن دیف (Diff Patching)**:
  - **SEARCH / REPLACE** (مشابه روش پیشرفته ابزار Aider همراه با تطبیق هوشمند Whitespace و تورفتگی).
  - **فرمت مبتنی بر شماره خط** (`INSERT_AFTER`، `INSERT_BEFORE`، `REPLACE: X-Y`، `DELETE`).
  - **ساخت خودکار فایل جدید** با مارکر `// NEW FILE`.
- 🛡️ **امنیت و کنترل کامل کاربر**: کدهای تغییریافته مستقیماً در ادیتور باز می‌شوند (بدون سیو اجباری) تا بتوانید تغییرات را بازبینی کرده و با `Ctrl+S` ذخیره یا با `Ctrl+Z` لغو کنید.
- ⚡ **سازگار با کلیپ‌بورد و سایدبار اختصاصی**: هم از طریق منوی کناری (Sidebar) و هم از طریق کلیدهای میانبر / Command Palette در دسترس است.
- 🚫 **نادیده‌گرفتن فایل‌های غیرضروری**: پشتیبانی پیش‌فرض از نادیده‌گرفتن `node_modules`، فایل‌های باینری، تصاویر، لاگ‌ها، Lockfileها و امکان سفارشی‌سازی در تنظیمات.

## 🚀 نحوه استفاده (Workflow ساده در ۳ مرحله)

[۱. کپی کانتکست با افزونه] ──▶ [۲. گفتگو در AI Playground] ──▶ [۳. اعمال پاسخ با
افزونه]


### ۱. کپی کانتکست پروژه
1. سایدبار **AI Diff Assistant** (آیکون ✨) را باز کنید.
2. پوشه‌هایی که مایلید AI درباره آن‌ها بداند را انتخاب کنید.
3. دکمه **«📋 کپی پرامپت + ساختار + سورس کد»** را بزنید.

### ۲. ارسال به پلی‌گراند دلخواه (مثلاً Google AI Studio)
- وارد [Google AI Studio](https://aistudio.google.com) (یا هر هوش مصنوعی دیگر) شوید.
- متن کپی‌شده را Paste کنید و درخواست خود را مطرح کنید (مثلاً: *«تابع احراز هویت را به src/auth.ts اضافه کن»*).
- هوش مصنوعی پاسخ را در قالب بلاک‌های پچ تولید می‌کند.

### ۳. اعمال تغییرات روی پروژه
- پاسخ کامل هوش مصنوعی را کپی کنید.
- در سایدبار افزونه در کادر پایین Paste کرده و دکمه **«🚀 اعمال هوشمند تغییرات»** را بزنید.
- **یا** کافیست کلید `Ctrl+Shift+P` را زده و دستور `AI Assistant: Apply AI Code Response` را انتخاب کنید تا مستقیماً از کلیپ‌بورد شما تغییرات اعمال شود!

## 📐 فرمت‌های پشتیبانی‌شده پچ

هوش مصنوعی با دستورالعمل داخلی این افزونه، به دو شیوه کد تحویل می‌دهد که هر دو به‌صورت ۱۰۰٪ خودکار شناسایی و اعمال می‌شوند:

### فرمت ۱: SEARCH / REPLACE (پیش‌فرض و استاندارد)
```typescript
// FILE: src/services/user.ts
<<<<<<< SEARCH
export function getUser(id: string) {
    return db.users.find(id);
}
=======
export async function getUser(id: string) {
    const user = await db.users.find(id);
    if (!user) throw new NotFoundError('User not found');
    return user;
}
>>>>>>> REPLACE

فرمت ۲: شماره خط (Line Operations)

// FILE: src/utils/math.ts
// REPLACE: 12-15
function add(a: number, b: number): number {
    return a + b;
}

فرمت ۳: ایجاد فایل جدید

// FILE: src/types/config.ts
// NEW FILE
export interface AppConfig {
    port: number;
    host: string;
}

⚙️ تنظیمات افزونه (Settings)

در تنظیمات VS Code می‌توانید موارد زیر را شخصی‌سازی کنید:

| تنظیم                            | پیش‌فرض                                                          | توضیحات                                     |
| :------------------------------- | :--------------------------------------------------------------- | :------------------------------------------ |
| `aiDiffAssistant.excludeFolders` | `[]` (موارد پیش‌فرض: `node_modules`, `.git`, `dist`, `out`, ...) | پوشه‌هایی که باید از کانتکست خروجی حذف شوند |
| `aiDiffAssistant.excludeFiles`   | `[]` (موارد پیش‌فرض: `*.log`, `*.lock`, `*.png`, ...)            | الگوهای گلوب برای فایل‌های مستثنی‌شده       |

⌨️ دستورات Command Palette (Ctrl+Shift+P)

  - AI Assistant: Copy Project Context & System Prompt — کپی کانتکست کامل و
    پرامپت سیستم به همراه انتخاب پوشه
  - AI Assistant: Copy Project Structure Only — کپی فقط ساختار درختی پروژه
  - AI Assistant: Apply AI Code Response — اعمال مستقیم تغییرات کپی شده در
    کلیپ‌بورد
