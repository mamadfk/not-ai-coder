# برنامه رفع ایرادات پلاگین VSCode (AI Code Diff Assistant)

## 🔍 خلاصه ایرادات پیدا شده

### باگ‌های بحرانی
1. **تضاد منطقی پچر** (`aiPatcher.ts`): ادعای incremental است اما در عمل کل فایل را overwrite می‌کند. `// remove` هرگز چیزی حذف نمی‌کند و اگر AI فقط یک متد بفرستد، کل فایل از بین می‌رود.
2. **نبود فیلتر پوشه/فایل ناخواسته**: `node_modules`, `.git`, `out`, `dist` و فایل‌های باینری وارد کانتکست می‌شوند → UI پر از نویز و انفجار توکن.
3. **Path Traversal**: مسیر `../../etc/passwd` یا مطلق خارج workspace بدون چک نوشته می‌شود؛ `mkdirSync` خارج workspace دایرکتوری می‌سازد.
4. **XSS در Webview**: نام پوشه با `innerHTML` بدون escape تزریق می‌شود.
5. **`fs.writeFileSync` به جای `WorkspaceEdit`**: تغییرات Undo نمی‌شوند و فایل باز در ادیتور refresh نمی‌شود.

### باگ‌های متوسط
6. **درخت ساختار اشتباه**: `depth = rel.split('/').length` باعث تورفتگی نادرست می‌شود و ریشه نشان داده نمی‌شود؛ فقط flat list با `├──`.
7. **QuickPick custom property** (`folder`) unsafe است — باید `description` یا map استفاده شود.
8. **`hasDiffMarkers` محاسبه می‌شود ولی بی‌استفاده** (dead code).
9. **عدم CSP nonce** در webview → هشدار امنیتی VS Code.
10. **`err: any` در ۷ جا** به جای `err: unknown` با type narrowing.

### مشکلات جزئی/تمیزکاری
11. تکرار زیاد کد در `extension.ts` (سه command تکراری) و `sidebarProvider.ts` (سه handler).
12. نبود `.vscodeignore` (vsix احتمالاً node_modules/src را شامل می‌شود).
13. پشتیبانی نشدن Multi-root workspace (همیشه `workspaceFolders[0]`).
14. regex `blockRegex` با code fence تودرتو/محتوای ``` درون کد مشکل دارد.

## 🛠️ برنامه اجرا (ترتیب پیاده‌سازی)

### مرحله ۱ — اصلاح Patcher (`src/patcher/aiPatcher.ts`) *[حیاتی]*
- **حذف تضاد**: پچر را واقعاً incremental می‌کنم به‌طوری‌که مطابق با پاسخ شما (بهبود Incremental) کار کند:
  - اگر فایل **موجود نباشد** یا `NEW FILE` باشد → ساخت فایل کامل جدید.
  - اگر فایل **موجود باشد و marker وجود داشته باشد** → اعمال partial واقعی روی محتوای فعلی فایل:
    - `// new` / `# new`: بلوک را **بعد از** خط مشخص‌شده (یا انتهای فایل) درج می‌کند.
    - `// change`: خطوط قبل از marker را با خطوط جدید جایگزین می‌کند (تشخیص scope با `function`/`class`/`def`/`{...}` یا روش anchor ساده).
    - `// remove: [code]`: خطوط منطبق با کد قدیمی را حذف می‌کند.
    - وقتی هیچ marker نیست و فایل موجود است → complete replacement (رفتار فعلی، اما حالا صریح و مستند).
  - اگر فایل موجود باشد و **هیچ‌کدام از منطق‌ها تطبیق نکنند**، بدون overwrite مخرب، یک پیام خطای واضح برمی‌گرداند.
- **امنیت Path Traversal**: تابع `ensureInsideWorkspace(targetPath, workspaceRoot)` اضافه می‌کنم که با `path.relative` چک می‌کند مسیر داخل workspace بماند و با `..` یا مطلق خارج از آن خارج نشود. `mkdirSync` و `writeFileSync` فقط پس از عبور از این چک اجرا می‌شوند.
- **استفاده از `vscode.WorkspaceEdit`** به جای `fs.writeFileSync` تا Undo و refresh خودکار ادیتور کار کند.
- تمیزکاری: حذف dead code (`hasDiffMarkers`)، تبدیل `err: any` به `err: unknown`.

### مرحله ۲ — فیلتر کانتکست (`src/exporter/contextExporter.ts`) *[حیاتی]*
- اضافه کردن لیست پیش‌فرض هاردکد شده ignore: `node_modules`, `.git`, `.vscode`, `.idea`, `dist`, `build`, `out`, `.next`, `coverage`, `__pycache__`, `.cache`, `*.log`, `*.min.js`, `*.map`.
- اضافه کردن تشخیص فایل بایناری (پسوندهای `png/jpg/jpeg/gif/ico/pdf/zip/exe/dll/so` و چک کاراکتر null).
- طبق پاسخ شما (هاردکد + تنظیمات): به `package.json` یک بخش `contributes.configuration` اضافه می‌کنم با کلید `aiDiffAssistant.excludeFolders` و `aiDiffAssistant.excludeFiles` (آرایه glob)، که لیست هاردکد را override/extend می‌کند.
- اصلاح `buildTreeString`: ساخت درخت **واقعی** با شاخه‌بندی `├──`/`└──` و تورفتگی صحیح (depth-1)، نمایش ریشه `.`.
- رفع QuickPick: استفاده از `description` برای ذخیره نام پوشه (API-بخش مطمئن) یا نگه‌داری map جدا.

### مرحله ۳ — امنیت Webview (`src/ui/sidebarProvider.ts`) *[حیاتی]*
- **XSS**: جایگزینی `innerHTML` با `createElement` + `textContent` یا تابع `escapeHtml`.
- **CSP nonce**: اضافه کردن `<meta http-equiv="Content-Security-Policy">` با nonce در script tag.
- تمیزکاری: فاکتورگرفتن workspace-check تکراری به یک helper، تبدیل `err: any` به `err: unknown`.

### مرحله ۴ — تمیزکاری `extension.ts` + Multi-root
- فاکتورگرفتن بلوک تکراری workspace-check در سه command به helper.
- تبدیل `err: any` به `err: unknown`.
- (طبق پاسخ «همه رو انجام بده») پشتیبانی Multi-root: اگر بیش از یک workspace folder وجود داشت، QuickPick برای انتخاب folder نمایش داده می‌شود.

### مرحله ۵ — Packaging و متادیتا
- ایجاد **`.vscodeignore`** برای استثنا کردن `node_modules`, `src`, `tsconfig.json`, `.vscode`, `*.vsix`, `package-lock.json`.
- ایجاد **`.gitignore`** برای `node_modules`, `out`, `*.vsix`.
- به‌روزرسانی `package.json`: افزودن `contributes.configuration`، `repository`/`license`/`author` (اختیاری اما حرفه‌ای)، و نگه‌داشتن `engines`.
- **recompile**: `npm run compile` تا `out/` همگام شود و با type-check تأیید نهایی.
